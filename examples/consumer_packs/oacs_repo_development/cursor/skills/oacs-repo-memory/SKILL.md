# Deprecated OACS Repository Shim

Use the globally installed `oacs` Skill for retrieval, evidence, checkpoints,
and recovery. Use the globally installed `proof-loop` Skill for acceptance
criteria and fresh verification. This shim contains no copy of either protocol
and can be removed after `acs integrations cursor install` succeeds.
