OACS is the persistent context system for substantial repository work. Use the installed `oacs` Skill for context, evidence, checkpoints, and recovery. Use the installed `proof-loop` Skill when substantial implementation or release work needs explicit acceptance criteria and fresh verification. Project memory is the primary source for project-specific context; global memory is limited to relevant cross-project knowledge. After resume or compaction, restore current OACS task state before substantial continuation. Current explicit user instructions always override stale OACS state or historical memory.
